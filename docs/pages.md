# Pages — экраны, состояния и переходы

Общие состояния: **loading** — кнопка действия в состоянии загрузки (~0,5 с); **empty** — `EmptyState` с подсказкой; **error** — текст под полем и toast; **success** — toast и обновлённые данные. Мобильная версия: одна колонка, Sheet-меню, таблицы с горизонтальной прокруткой внутри.

| Маршрут | Назначение | Секции | Действия и состояния |
|---|---|---|---|
| `/` | Лендинг | Hero, преимущества, «Как это работает», популярные пакеты, учителя, отзыв, CTA | Выбрать пакет, демо-вход, регистрация |
| `/packages` | Каталог | Фильтры (поиск, предмет, класс, язык, цена, сортировка), карточки | Подробнее; empty при пустом результате |
| `/packages/:id` | Детали пакета | Условия, предметы, учителя, sticky-блок цены | Купить; у архивного покупка недоступна |
| `/teachers`, `/teachers/:id` | Только опубликованные | Фильтры; профиль: компетенции, стаж, статистика, отзывы | Неопубликованный профиль → «недоступен» |
| `/demo`, `/register` | Демо-вход, регистрация | Роли, профили, подсказки по P-01…P-06; формы родителя и ученика | Вход, сброс демо |
| `/checkout/:packageId[?renew=id]` | P-01 / P-06 | Степпер: конфигурация (в пакете «на выбор» — выбор ровно K предметов; «назначено X из N») → семья → оферта и демо-оплата → результат | Оплата заблокирована без оферты; «Отклонено» → повтор; повторный webhook |
| `/parent` | Сводка родителя | Неоплаченные заказы, KPI, дети с квотами, ближайшие уроки, быстрые действия | Купить, продлить, перераспределить |
| `/parent/children` | Дети | Карточки, диалог создания и редактирования | Валидация имени, класса, года рождения |
| `/parent/orders` | Пакеты и квоты | Общий остаток по ребёнку × заказы; заказы: куплено / списано / резерв / свободно / истекло | Оплатить (демо), перераспределить, продлить, история квот |
| `/parent/orders/:id/allocate` | P-05 | Таблица заблокированных и свободных уроков, редактор, журнал | Ошибка суммы или тарифа — данные не меняются |
| `/parent/calendar`, `/parent/feedback` | Расписание, обратная связь | Календарь с фильтром по ребёнку; заметки учителей (видны только родителю) и оценки ребёнка | Только просмотр |
| `/student`, `/student/calendar` | Ученик | Крупная карточка ближайшего урока, остатки, «Оцени урок» | Открыть тестовую Zoom-ссылку; после урока поставить учителю звёзды и отзыв. Заметки учителя ученику не показываются |
| `/teacher` | Учитель | KPI; вкладки: отчёты, предстоящие, календарь, история, группы | Заполнить отчёт |
| `/teacher/profile` | P-02 | Анкета: ФИО, фото-заглушка, предметы и классы, языки, стаж, категория, школа, биография | Черновик / отправить (с подтверждением) |
| `/teacher/lessons/:id/report` | P-04 | Факт проведения, тема, время, матрица посещаемости с заметкой по каждому ребёнку | Отправить → «Отчёт на проверке» |
| `/moderator` | Рабочая панель | KPI, очередь задач, «оплачено, но не запланировано», ближайшие уроки, журнал | Переходы в очереди |
| `/moderator/teachers` | P-02 | Вкладки по статусам, таблица, карточка анкеты, назначение роли | Одобрить, вернуть с замечанием, снять / вернуть публикацию |
| `/moderator/packages` | Пакеты | Таблица, диалог редактирования | Создать, опубликовать, архивировать; новая версия при коммерческих изменениях |
| `/moderator/groups` | Группы | Карточки групп с лимитом и квотами, таблица учеников | Создать группу, добавить / исключить ученика (с валидацией) |
| `/moderator/calendar[?create=1]` | P-03 | Фильтры, календарь, детали урока, диалог создания | Валидаторы блокируют публикацию; перенос и отмена |
| `/moderator/reports` | P-04 | Очередь, детали отчёта с прогнозом списания | Подтвердить / вернуть; повторное подтверждение идемпотентно |
| `/moderator/analytics` | Аналитика | Фильтры, KPI, таблицы по предметам, пакетам, учителям | Детализация: заказ → квоты → участие → урок |
| `/admin` | Админ-демо | Справочники, роли, журнал, демо-настройки | Добавить предмет, переключить роли, правило пропусков, сброс |
